# Лаб 3. Реалізація патерну Singleton

Виконав: Хмелівський Станіслав, варіант 27 «Продуктовий магазин».

Рішення `ShopSingleton.sln` складається з двох проєктів:

* `ShopLibrary` (бібліотека класів, збирається в `ShopLibrary.dll`) містить три класи-одинаки:
  1. `DbManager`: глобальна точка доступу до бази даних товарів магазину (файл `data/products.json`);
  2. `DocumentSaver`: глобальна точка доступу до сховища документів, тобто чеків продажів і звітів про залишки (папка `documents`);
  3. `Logger`: запис усіх дій користувача у файл `logs/log.txt`.

  Кожен клас має закритий конструктор і статичну властивість `Instance`, яка створює об’єкт тільки один раз (з блокуванням `lock` для безпечної роботи з потоками).
* `ShopApp` (Windows Forms) підключає `ShopLibrary.dll` і має кілька форм: головну, «Товари», «Продаж», «Документи», «Журнал дій». Усі форми працюють з тими самими екземплярами одинаків: внизу кожної форми видно однакові номери об’єктів, а кнопка «Перевірити Singleton» на головній формі показує, що кожен клас створено лише один раз.

Запуск: відкрити `ShopSingleton.sln` у Visual Studio і натиснути F5.
